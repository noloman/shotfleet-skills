# Where these files come from

I write the skills next to the shotfleet program, in a private repo. At each shotfleet release I copy them here
with a script, set the plugin version to the shotfleet version, read the diff and push it myself.

So please don't send changes to the files in `skills/` as pull requests: the next release would overwrite them.
Open an issue instead, or write to hello@shotfleet.com, and I'll fix it at the source.
